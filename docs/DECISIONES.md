# Decisiones

El repo público se llama `mini-no`. MINI-NO es el nombre de trabajo. Se mantiene Expo Router, pnpm, TypeScript y Supabase. La primera tanda implementa reglas independientes para tiempo disponible, energía y motivo de ausencia. Una molestia activa una revisión y un mensaje de cuidado, sin diagnosticar. La pantalla todavía no persiste datos. Invitados, nombre definitivo, profesional revisor y testers siguen abiertos.
